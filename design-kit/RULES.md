# Design kit rules

The contract for HTML screens (from Claude Design or any other source) that the pipeline compiles into Unity UI Toolkit and verifies against the design pixel for pixel. Lint enforces every rule below: anything outside the contract fails with a rule id and a fix, and is never approximated. This file is generated by `design-export kit build` from the kit and the lint's own data; edit the sources, not this file.

## A screen in brief

1. One page per screen. Its root element carries `data-u-screen="<screen.id>"` and is exactly 2560×1440 px (`width: 2560px; height: 1440px`) at (0, 0), `position: relative`. Screens are verified at 2560×1440, 1920×1080, 1280×720.
2. The style starts with the base stylesheet (`base.css`, below); it sizes boxes as UI Toolkit does and writes out every browser default.
3. Lay out with flex only. Colours, spacing, radii and shadows come from the tokens through `var(--name)`.
4. Every text uses a kit text style class (`.text-body`, `.text-title-bold`, …) and the kit font; never declare `@font-face`.
5. Visible text is written in the reference locale (tr) with a `data-l10n` key and the English `data-en`; runtime values use `data-u-bind` and sample text.
6. Interactive, bound and action elements carry `data-u-id`; actions name a command in `data-u-action`.
7. Interaction states are `:hover`, `:active`, `:focus`, `:disabled`, `:checked` and `is-*` classes; screen states are `data-u-state` roots shown under `.state-<name>`.
8. Every screen is linted before it goes to Unity (`design_ui_lint` in the MCP server, or `design-export lint <screen> --kit <kit>`); fix the design, never the generated Unity files.

## Claude Design canvases

When a screen is drawn in Claude Design, the kit is attached as a Design System and each screen is one artboard:

- One artboard per screen, titled with the screen id, with a fixed 2560×1440 root; states stay `data-u-state` roots inside it.
- Markup goes inside `<x-dc>`, page styles inside `<helmet><style>`; start that style with the kit stylesheet.
- No `{{…}}` holes (U-DC-001), no `<sc-for>`, `<sc-if>`, `<dc-import>` or `x-import` (U-DC-002), no UI built by script (U-DC-003), and no `data-props` other than `$preview` (U-DC-004).
- Repeated rows are written out as sample rows, with `data-u-repeat` on the first; the samples share its structure.
- Inline styles are allowed; they compile like rules.
- Images are uploads (`/_blob/<id>`) or inline `<svg>`; nothing is loaded from the network (U-NET-001). Fonts come only from the kit.

## Base stylesheet

`base.css` (generated from `text-styles.json`). Copy it unchanged to the top of every screen's style. It turns on grayscale font smoothing on the root (`-webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale`), so browsers on macOS draw glyph stems as thin as UI Toolkit does (lint requires it on every text, U-CSS-038); writes out every browser default lint would report (U-CSS-026); sizes every box as `border-box` (U-CSS-036); sets the kit font with the `label` style as the page default; and defines one class per text style. The kit's tokens (`tokens.css`) are loaded by the exporter; a Claude Design artboard pastes them too.

## Markup attributes

| Attribute | Meaning | Required |
|---|---|---|
| `data-u-screen` | Screen id on the root element, e.g. `club.overview` | yes, exactly once |
| `data-u-id` | Stable element name exposed to code | on every interactive, bound or action element |
| `data-l10n` | Localization key in meaningful English, e.g. `club.overview.title` | on every visible static text |
| `data-en` | English source text for that key (the element's own text is the reference-locale text) | with `data-l10n` |
| `data-u-arg` | On a `<span>` inside localized text: a Smart String argument with sample text; `data-en` writes it as `{name}` | when the text has variables |
| `data-l10n-args` | Smart String argument names, e.g. `amount,currency` | optional |
| `data-l10n-<attr>, data-en-<attr>` | Key and English text for `placeholder`, `title`, `alt`, `aria-label` | when such an attribute has text |
| `data-u-bind` | Dynamic, non-translated value (player name, number); the element's text is sample data | for runtime values |
| `data-u-action` | Command raised on activation, e.g. `open-inbox` | on actionable elements |
| `data-u-repeat` | Repeated item template, e.g. `players`; the written-out samples follow it | on the first sample item |
| `data-u-repeat-mode` | `list` (virtualized, the default inside a scroll area) or `inline` | optional |
| `data-u-state` | Screen state variant root, e.g. `loading`, `empty`, `error`; CSS shows it under `.state-<name>` | on state roots |
| `data-u-external` | Region drawn by the host (e.g. an existing uGUI shell); not compiled, masked in comparison | optional |

Ids, actions, binds, repeat names and state names are lowercase ASCII: `^[a-z0-9]+([._-][a-z0-9]+)*$`. Localization keys are ASCII in any letter case, exact and case-sensitive, spelled as the String Table key (`inbox.main.unreadOnly`): `^[A-Za-z0-9]+([._-][A-Za-z0-9]+)*$` (both U-MRK-005; no `İ`, `ı`, `ş`). Elements without `data-u-id` get structural names, so code never depends on them.
A variable inside localized text is `<span data-u-arg="name">sample</span>`, written `{name}` in `data-en`.

## Text styles

Every text uses exactly one of these size / line-height / weight combinations (U-CSS-016). Use the class: it sets all three.

| Style | Class | font-size (px) | line-height (px) | font-weight |
|---|---|---|---|---|
| caption | `.text-caption` | 12 | 16 | 400 |
| caption-bold | `.text-caption-bold` | 12 | 16 | 700 |
| label | `.text-label` | 16 | 20 | 400 |
| label-bold | `.text-label-bold` | 16 | 20 | 700 |
| body | `.text-body` | 24 | 32 | 400 |
| body-bold | `.text-body-bold` | 24 | 32 | 700 |
| subtitle | `.text-subtitle` | 32 | 40 | 400 |
| subtitle-bold | `.text-subtitle-bold` | 32 | 40 | 700 |
| title | `.text-title` | 36 | 48 | 400 |
| title-bold | `.text-title-bold` | 36 | 48 | 700 |
| headline | `.text-headline` | 48 | 60 | 400 |
| headline-bold | `.text-headline-bold` | 48 | 60 | 700 |
| display | `.text-display` | 64 | 80 | 400 |
| display-bold | `.text-display-bold` | 64 | 80 | 700 |

UI Toolkit cannot set a line height, so the kit's Unity font twins carry each style's CSS line box (whole pixels at every supported viewport): a text block is exactly lines × line height tall on both sides. Weights are 400 and 700 only, each with a real face in the reference locale's font (U-FONT-001); no italic unless the kit font has an italic face. Inside one line of text, `<b>`/`<strong>` and `<span>` with another colour or kit size are rich text; `<br>` breaks the line. The table is `text-styles.json`; every listing of it (this table, the base stylesheet's classes, the design system's type styles) is generated from that file.

Readability: caption and label are under 10 device px at 1280×720: keep them for secondary text (kit build and kit sync warn once).

## Fonts

The fonts come from the Unity project: kit sync copies the font files the project's TMP setup renders each locale with into `fonts/` and writes `fonts/fonts.css` and `fonts/fonts.json`. The exporter loads only those. Use `font-family: var(--font-ui)` (the base stylesheet sets it on the page); never declare `@font-face` (U-FONT-002) and never name another family (U-CSS-010). A character the kit font lacks fails lint (U-FONT-003) instead of falling back to another font.

## Layout

- `display: flex` (rows and columns, `flex-wrap` for tiles) or `none`; `display: block` becomes a flex column. No grid (U-CSS-001), no floats or `position: fixed/sticky` (U-CSS-017).
- `gap` only on containers that do not wrap (U-CSS-011); it becomes margins. Sizes in px or %; no `calc()` (U-CSS-005) and no viewport units (U-CSS-006).
- `position: absolute` needs a positioned parent (U-CSS-035); `z-index` only where the markup order already gives the paint order (U-CSS-004, U-CSS-032).
- Give flex items an explicit size or `flex-shrink: 0` where their content must not shrink (U-CSS-019); `align-items: baseline` is not available (U-CSS-018).
- Move, turn and scale with `translate`, `rotate`, `scale` (or a `transform` of those functions in that order, U-CSS-025).
- Text sits in its own element: no text next to element children (U-CSS-030); a single inline child of a block becomes a block only when it renders the same (U-CSS-009).
- `overflow: hidden` clips; `overflow-y: auto` makes a scroll area (a `ScrollView`), and a `data-u-repeat` list inside one becomes a virtualized `ListView`.

## Interaction and screen states

- `:hover`, `:active`, `:focus`, `:disabled` and `:checked` on the element itself or on an ancestor (`.card:hover .title`). UI Toolkit presses one element at a time and focuses one element at a time, so style a press or focus on one element of a chain, not on both an ancestor and the element (U-CSS-033).
- Custom states are `is-*` classes the generated view toggles (`.tab.is-selected`); screen states are `.state-<name>` on the screen root, with the state's content in a `data-u-state` root. Mark the initial state in the markup.
- No sibling combinators, `:nth-*`, `:first-child`, `:not()` or `:has()` (U-CSS-003, U-CSS-027). A `gap` container whose earlier child hides itself by its own state is U-CSS-034.
- Every state, pseudo-state and class layer is captured and compared on its own, also when it changes only a shadow or a gradient.

## Effects

- `box-shadow` (outer and `inset`, several per element) is baked by the exporter into a 9-slice image per style layer. An inset shadow cannot sit on an element with its own text, on a form control or on a scroll area (U-CSS-037); put it on a wrapper.
- `linear-gradient()` and `radial-gradient()` are baked into a vector image that fills the element; colour stops at least 1/64 of the gradient line apart (U-CSS-022), sRGB stops only (U-CSS-014). One background image per element (U-CSS-037).
- `text-shadow`: one shadow, `x y blur colour` (several are U-CSS-023). `border-style`: `solid` or `none` (U-CSS-021). Corner radii are circular, one px value per corner (U-CSS-020; % only on squares, a pill uses half the height).
- `object-fit`: `fill`, `contain` or `cover`, centred, on images. Icons are inline `<svg>`: paint every shape with `currentColor` to follow the text colour in every state, or every shape with fixed colours (U-CSS-031).
- `filter`: only the functions css-support.json enables, each once its fidelity fixture passes in Unity (U-CSS-015; `kit.config.json` `filterFunctions` mirrors the list); currently `invert`. No `backdrop-filter` (U-CSS-007), no `outline` (draw focus with a border).

## Animation

- Transitions and `@keyframes` are recorded with their trigger (the screen opening, a screen state, a pseudo-state or an `is-*` class) and played by the package's animation player, never as USS transitions.
- Timing: the keywords, `cubic-bezier()` (x 0–1) or `steps()`; no `linear()` points (U-CSS-008). Keyframes and transitions animate only transforms, `opacity` (one-part elements, U-CSS-039), colours and border radii (U-CSS-013, U-CSS-042): a size or position change is a `translate` or `scale`, never a layout property; `box-shadow` or `background-image` fails (U-CSS-014). One property of an element is animated by keyframes or by a transition, not both (U-CSS-043).
- Verification samples each animation at its delay and every quarter of its duration. A trigger the artboard starts in (`is-open` in the markup) shows its end state.

**Value functions:** `var()`, `rgb()`, `rgba()`, `hsl()`, `hsla()`, `linear-gradient()`, `radial-gradient()`, `url()`, `invert()`. **Transform functions:** `translate`, `translatex`, `translatey`, `scale`, `scalex`, `scaley`, `rotate`.
**Timing functions:** `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `step-start`, `step-end`, `cubic-bezier()`, `steps()`. **Keyframe properties:** see Animation.
**Pseudo-classes:** `:hover`, `:active`, `:focus`, `:disabled`, `:checked`, `:root`. **Pseudo-elements:** `::before`, `::after`, `::placeholder` (`::before`/`::after` only without content).
**At-rules:** `@media`, `@keyframes`, `@import` (kit files only), `@font-face` (kit files only); `@media` features `min-width`, `max-width`, `min-aspect-ratio`, `max-aspect-ratio`, media types `all`, `screen`.
**Elements:** `body`, `div`, `span`, `p`, `h1`, `h2`, `h3`, `h4`, `h5`, `h6`, `button`, `input`, `textarea`, `select`, `option`, `label`, `img`, `svg`, `br`, `ul`, `ol`, `li`, `a`, `section`, `header`, `footer`, `nav`, `main`, `aside`, `article`, `b`, `strong`, `i`, `em`, inline `<svg>` (exported as a vector image; SVG presentation attributes allowed inside). **`<input>` types:** `text`, `search`, `password`, `number`, `email`, `tel`, `url`, `checkbox`, `radio`.

## Lint rules

Errors (`U-`) block export and import; warnings (`W-`) and information (`I-`) are reported. Each finding names the element, the declaration and a detailed fix.

| Rule | Severity | Fails when | Fix |
|---|---|---|---|
| U-CSS-001 | error | `display: grid` or `inline-grid` | nested flex rows and columns (`flex-wrap` for tiles) |
| U-CSS-002 | error | `::before` / `::after` with content, or list markers | a real element; `list-style: none` |
| U-CSS-003 | error | structural selectors (`:nth-*`, `:first/last/only-child`, `:*-of-type`, `:empty`) | a class per element |
| U-CSS-004 | error | a `z-index` or sibling order UI Toolkit's hierarchy order cannot reproduce: a z-index outside the base layer, on a static non-flex-item, against the markup order of in-flow siblings, or an absolute sibling with no place among them where CSS paints it | z-index in the base style only, on absolute or relative elements or flex items that follow the markup order; otherwise reorder the markup, or give the in-flow siblings the same position |
| U-CSS-005 | error | `calc()` | a literal value |
| U-CSS-006 | error | viewport units (`vw`, `vh`, `vmin`, `vmax`, …) | px or % |
| U-CSS-007 | error | `backdrop-filter` | a solid or translucent colour, or a baked image |
| U-CSS-008 | error | a `linear()` easing with points | a keyword, `cubic-bezier()` or `steps()` |
| U-CSS-009 | error | an inline element in text flow other than `b`, `strong`, `i`, `em`, `span`, `br`, a rich tag with effects beyond colour, size, bold and italic, or one in a block container that cannot be a block | `display: block` on the child or `display: flex` on the parent; inside a line only the rich tags |
| U-CSS-010 | error | a first font family that is not a kit family | a kit family first (`var(--font-ui)`) |
| U-CSS-011 | error | `gap` on a wrapping flex container | margins on the items |
| U-CSS-012 | error | `@media` features other than min/max-width and min/max-aspect-ratio, media types other than screen/all, `not` | the allowed features only |
| U-CSS-013 | error | `@keyframes` animating what the animation player cannot (a layout property, letter-spacing, shadows, …) | transforms, opacity, colours, radii; translate or scale for size and position |
| U-CSS-014 | error | a transition of `box-shadow` or `background-image`, a url() image beside another image, a gradient that does not fill the element or sets a colour space | transition a transform; one image per element; whole-element sRGB gradients |
| U-CSS-015 | error | a `filter` function css-support.json does not enable (one is enabled once its fidelity fixture passes in Unity) | remove the filter |
| U-CSS-016 | error | text size, line height or weight that is not a kit text style | the nearest kit text style (a `.text-<style>` class) |
| U-CSS-017 | error | `position: fixed/sticky`, `float` | absolute positioning or flex |
| U-CSS-018 | error | `baseline` in align-items/align-self/align-content | flex-start, center or flex-end (top margin to line up baselines) |
| U-CSS-019 | error | a flex item's layout depends on `min-width/min-height: auto` | an explicit min size in px, or `flex-shrink: 0` |
| U-CSS-020 | error | elliptical corner radii (`/` syntax, % on a non-square box) | one px radius per corner; a pill uses half the height |
| U-CSS-021 | error | border style other than solid or none | solid; draw dashed or dotted lines as SVG |
| U-CSS-022 | error | gradient colour stops closer than 1/64 of the gradient line (hard stops), colour hints | split the area at the hard edge, or spread the transition |
| U-CSS-023 | error | a property, keyword, colour keyword or unit outside the allowed CSS | remove it or use the allowed CSS |
| U-CSS-024 | error | a value function other than var, rgb(a), hsl(a), linear-/radial-gradient, url | a literal value |
| U-CSS-025 | error | a transform not expressible as translate → rotate → scale (matrix, skew, perspective, 3D) | 2D functions in that order, or the `translate`, `rotate`, `scale` properties |
| U-CSS-026 | error | a browser default style the design did not write (margins, paddings, borders, link colour, `appearance: auto`, …) | include the kit base stylesheet, or write the property (`margin: 0`, `appearance: none`, …) |
| U-CSS-027 | error | pseudo-classes other than hover/active/focus/disabled/checked, `+` / `~`, `:is/:where/:has/:not` | style the element itself, or `is-*` classes |
| U-CSS-028 | error | at-rules other than `@media` and `@keyframes` | no @layer/@supports/@container/@starting-style/@property/@page/@import |
| U-CSS-029 | error | an element outside the whitelist, an unsupported input type, a shadow root, `<foreignObject>` | the listed elements and inline `<svg>`, light DOM only |
| U-CSS-030 | error | collapsing vertical margins, or text next to element children | flex column with gap or padding; wrap text in its own element |
| U-CSS-031 | error | an inline SVG that paints some shapes with currentColor and others with fixed colours | currentColor on every shape (the icon follows its element's colour) or fixed colours on every shape |
| U-CSS-032 | error | overlapping siblings UI Toolkit paints in another order than CSS (a relative sibling before a static one, a faded or transformed static one after an absolute one) | the same paint level for the siblings (position: relative), the top one later in the markup, or move them apart |
| U-CSS-033 | error | pseudo-states a pointer or focus cannot produce together: `:active` on an ancestor and on the element, two focused elements | style one press or focus per element; an `is-*` class set by code for a combined look |
| U-CSS-034 | error | a `gap` container whose earlier child shows or hides by its own pseudo-state or `is-*` class | use a screen state or an ancestor's class, keep an always-visible child first, or margins instead of gap |
| U-CSS-035 | error | an absolute element whose parent is static, or that changes position between layers | `position: relative` on the parent; one position in every layer |
| U-CSS-036 | error | `box-sizing: content-box` on an element with a width or height and padding or border | `box-sizing: border-box` (the kit base stylesheet sets it everywhere) |
| U-CSS-037 | error | baked effects that cannot share one element: an inset shadow under its own text, on a form control or a scroll area; a url() image beside a gradient or only in a layer; a background image or inset shadow on a tintable icon | move the text, image, gradient or icon into a child, or the shadow onto a wrapper |
| U-CSS-038 | error | text without `-webkit-font-smoothing: antialiased` (macOS browsers thicken its stems, UI Toolkit does not) | the kit base stylesheet (it sets it on `:root`); never override it |
| U-CSS-039 | error | `opacity` < 1, or a fade of it, on overlapping parts | `--color-disabled-*` colours; no fade |
| U-CSS-040 | error | a border, hard shadow edge or painted line under 8px off the device grid | the listed lengths |
| U-CSS-041 | error | a positioned or moved box or shadow over later elements | room, or `position: relative` on later ones |
| U-CSS-042 | error | a transition of a property the animation player cannot animate (a layout property, letter-spacing, `visibility`, …) | transition transforms, opacity or colours; translate or scale for size and position |
| U-CSS-043 | error | `@keyframes` and a transition of the same property on one element | one of them; the other on another property or a wrapper |
| U-DC-001 | error | `{{…}}` holes in a Claude Design artboard | static sample text |
| U-DC-002 | error | `<sc-for>`, `<sc-if>`, `<dc-import>`, `x-import` | write rows out, `data-u-repeat` on the first |
| U-DC-003 | error | UI built by script | static markup |
| U-DC-004 | error | `data-props` other than `$preview` | static values |
| U-DC-005 | error | markup outside `<x-dc>`, or no `<x-dc>` | everything inside `<x-dc>` |
| U-FONT-001 | error | a weight or italic without a real face in the reference locale's font | weight 400 or 700 (or add the real face in Unity and kit sync) |
| U-FONT-002 | error | `@font-face` or FontFace not from the kit | remove it; use the kit fonts |
| U-FONT-003 | error | glyphs drawn by a platform or non-kit font (character missing in the kit font) | characters the kit font covers |
| U-MRK-001 | error | not exactly one `data-u-screen` | one screen root with `data-u-screen` |
| U-MRK-002 | error | duplicate `data-u-id` | unique ids (each repeat item is its own scope) |
| U-MRK-003 | error | interactive, bound or action elements without `data-u-id` | add `data-u-id` |
| U-MRK-004 | error | visible text without `data-l10n` + `data-en` on the element holding it (or `data-u-bind`) | add the key and English text |
| U-MRK-005 | error | ids, actions or names outside `^[a-z0-9]+([._-][a-z0-9]+)*$`, or localization keys outside `^[A-Za-z0-9]+([._-][A-Za-z0-9]+)*$` (any letter case) | ASCII transliteration (no İ, ı, ş, …); keys spelled exactly as the String Table key |
| U-MRK-006 | error | the screen root is not the kit reference size at (0, 0) | root `width/height` = reference in px, `body { margin: 0 }` |
| U-MRK-007 | error | placeholder, title, alt or aria-label text without `data-l10n-<attr>` + `data-en-<attr>` | add the key and English text per attribute |
| U-MRK-008 | error | a variable inside localized text not marked as `<span data-u-arg="name">` with one `{name}` in `data-en` | one `data-u-arg` span per `{name}` placeholder; `data-l10n-args` (optional) lists the same names |
| U-MRK-009 | error | a keyed, bound, id'd or action inline element sharing a line with other text, tags or spaces, or changing font size or line height in the line | its own block element (or a flex row of them); `data-u-arg` for a variable inside one text |
| U-MRK-010 | error | a `data-u-repeat` container with other children, a sample whose structure differs from the template, or a mode other than list/inline | only the items in the container, samples with the template's elements, ids, keys and binds |
| U-MRK-011 | error | a `data-u-id` that gives a member the generated view class already has (`state`, `set-state`, `find`, `screen-root`, …) | another id, e.g. `state-label` |
| U-MRK-012 | error | a `data-u-action` element inside another `data-u-action` element | one action per element; a button in a card: the card's action on a full-size layer element beside the button, not on the card container |
| U-NET-001 | error | any remote resource (fonts, stylesheets, images) except scripts from allowed origins | no remote resources; local files |
| U-NET-002 | error | a local file or Claude Design blob that is missing | add the file, or map the blob in blobs.json |
| W-FONT-001 | warning | a weight or italic without a real face in another active locale's font (warning) | add the face or avoid the weight |
| W-FONT-002 | warning | a kit font file that cannot be read (WOFF2, `local()`) (warning) | TTF/OTF/WOFF via `url()` |
| I-MRK-001 | info | a `title` attribute: a tooltip, which UI Toolkit shows only in Editor panels (info) | nothing for an Editor-only hint; show hints players need with a visible element |

## Components

Each component is a lint-clean screen in `components/` with its guidelines next to it (`<name>.md`); copy its markup and classes, then adapt the content.

**Controls**

- **Button** (`components/button.html`): A button runs one command when it is pressed: primary, secondary, ghost and destructive styles in two sizes.
- **Toggle** (`components/toggle.html`): Toggles switch one setting on or off: a checkbox, a radio group and a switch, each with its label next to it.
- **TextField** (`components/text-field.html`): Text fields take typed input: single-line fields, a search field and a multi-line notes area, each with a label above it.
- **Dropdown** (`components/dropdown.html`): A dropdown picks one value from a short list: a select box with a chevron icon drawn over it.

**Navigation**

- **Tabs** (`components/tabs.html`): Tabs switch between views of one screen: a row of tab buttons with an underline on the selected tab and one panel per tab.

**Containers**

- **Card** (`components/card.html`): Cards group related content on a raised surface: a card with a gradient header and an action, a clickable card that lifts on hover, and a sunken well.
- **Dialog** (`components/dialog.html`): A dialog asks for a decision over the current screen: a scrim over the whole screen, a centred panel with a title, text and two buttons.

**Lists**

- **ListRow** (`components/list-row.html`): List rows show one record each in a column of rows: an avatar, a name, a position and a rating, under a header row.
- **ScrollArea** (`components/scroll-area.html`): Scroll areas show more content than fits: a scrolling text panel and a scrolling message list.
